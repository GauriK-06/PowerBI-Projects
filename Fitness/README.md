# 🏋️ Fitness Tracker & Health Analytics Dashboard

## 📌 Overview

An interactive Power BI dashboard designed to analyze fitness activities, user demographics, workout performance, and health-related metrics. 
It provides insights into calories burned, daily steps, workout duration, sleep patterns, and activity performance across different age groups and genders.

## 📊 Key Features

* **KPI Overview:** Displays total calories burned, average daily steps, total workout hours, average sleep hours, and active users.
* **Activity Performance Comparison:** Compares calorie expenditure across different workout activities and genders.
* **Device Share & User Demographics:** Analyzes fitness tracker usage across devices such as Apple Watch, Fitbit, Garmin, Mi Band, and Samsung Galaxy devices.
* **Workout Timing & Heart Rate Analysis:** Compares average heart rate across activity types and age groups.
* **Yearly Fitness Trends:** Visualizes yearly changes in total steps and calories for 2024 and 2025.
* **Interactive Filters:** Enables filtering by age group, activity type, and gender.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Cleaning and Transformation
* Data Visualization

## 🎯 Objectives

* Analyze fitness activity and workout performance.
* Understand user demographics and fitness device preferences.
* Compare activity patterns across age groups.
* Monitor key fitness indicators through interactive visualizations.
* Present fitness data in a clear and accessible format.
