# Executive Fintech & Loan Portfolio Overview

## Overview

An interactive Power BI dashboard designed to analyze loan portfolio performance, lending trends, customer segments, and repayment status. 
It provides key insights into portfolio value, loan distribution, interest rates, and default rates to support data-driven financial analysis.

## Key Features

* **KPI Cards:** Total Portfolio Value, Total Loans, Average Interest Rate, Default Rate, and Average Loan Size.
* **Monthly Loan Trends:** Tracks loan volume over time.
* **Portfolio Breakdown:** Analyzes portfolio value by loan product type.
* **Acquisition Channel Analysis:** Compares loan volumes across app, website, and partner channels.
* **Customer Segmentation:** Examines loan distribution across different customer segments and products.
* **Repayment Analysis:** Visualizes paid, ongoing, overdue, and defaulted loans.
* **Credit Risk Analysis:** Compares average credit scores and default rates across customer segments.

## Tools & Technologies

* Microsoft Power BI
* Data Analysis
* Data Visualization
